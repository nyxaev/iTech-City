## 🌌 Overview

**iTech-City** is an interactive project that lives in two worlds at once. Same city, two completely different moods: one is lit up and electric, the other is quiet, broken and slightly wrong.

> **🏙️ Cidade Neon** is high-contrast cybernetic visuals, vibrant glowing hues, synthwave aesthetics and futuristic city vibes.
>
> **👁️ Dreamcore Error** is glitch art, surreal liminal spaces, VHS distortion, nostalgia and a psychological, eerie ambiance.

## 🎭 Pick your reality

| | 🌃 **Cidade Neon** | 📼 **Dreamcore Error** |
|---|---|---|
| **Tagline** | *Cybernetic lights & infinite reflections* | *Surreal glitches & forgotten memories* |
| **Mood** | Electric, futuristic, high-energy | Nostalgic, liminal, uneasy |
| **Visual language** | High-contrast cyber visuals, glowing hues, synthwave | Glitch art, VHS distortion, surreal liminal spaces |
| **Effects** | Smooth ambient CSS glows, futuristic interface components | CRT and VHS scanlines, interactive distortion elements |
| **Feels like** | Driving through a glowing city at 2 AM | A memory you are not sure ever happened |

## 🚀 Quick start

**1. Clone the repository**

```bash
git clone https://github.com/nyxaev/iTech-City.git
cd iTech-City
```

**2. Open it**

Open `index.html` in your browser, or serve it locally:

```bash
python -m http.server 8000
```

Then go to `http://localhost:8000`.

> 💡 **Best experience:** full screen, dark room, volume up.
