## 🌌 Overview

Welcome to **iTech-City**, an interactive project featuring two distinct visual landscapes:

* 🏙️ **Cidade Neon (Neon City):** High-contrast cybernetic visuals, vibrant glowing hues, synthwave aesthetics, and futuristic city vibes.
* 👁️ **Dreamcore Error:** Glitch art, surreal liminal spaces, VHS distortion, nostalgia, and psychological eerie ambiance.
